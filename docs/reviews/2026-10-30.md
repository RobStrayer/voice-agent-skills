# Source review: October 30, 2026

[Documentation review](../documentation-review.md) / [Maintenance](../maintenance.md)

Sources retrieved October 29 and 30, 2026 UTC. Publication dates below belong to the
provider, regulator or release; "living" marks a page with no publication date. No
installer, inference request, voice call, or third-party helper was run. This review
covers changes published since [September 30](2026-09-30.md) and a few that the
September review missed, which are marked.

## How it was run

- The weekly upstream check ("Upstream changes", last run October 26) listed drift in
  two bundled collections, 25 linked repositories and 28 docs-hosted skills. GitHub's
  API was not reachable from the review environment, so `scripts/check_upstream.py` ran
  with repository heads read through `git ls-remote` and file trees through shallow
  fetches. Its comparison and `--apply` logic were unchanged. Archive, rename and
  licence status were not re-checked here; the October 26 workflow run reported none.
- The original material was checked by area against primary sources: speech-to-speech
  models and platforms; frameworks, turn detection and speech APIs; telephony and
  compliance; install paths, language models and skill format; and the linked index.
  The refreshed bundled copies were read in full for security and substance.
- A separate check of the finished change against primary sources found two errors,
  a link wrongly reported as gone and Eleven Realtime token rates wrongly reported as
  unpublished, plus several claims worded too strongly. All were corrected before
  publication.

## Bundled skills

- **ElevenLabs** moved from `279173d` to `503d4e9`: 29 changed files across all seven
  skills, read in full. Procedures no longer have a compile step, agents default to
  `eleven_v4_turbo`, text-to-speech examples default to `eleven_v4`, the Python realtime
  transcription API changed, and the voice-changer REST paths moved.
- **New:** ElevenLabs `realtime` (three files, MIT). It fills the agents skill's pointer
  to a realtime skill that was not bundled. Its Step 0 inventory command puts the brace
  pattern in quotes, so grep matches no files; the install guide gives the fix.
- **Security note:** every ElevenLabs setup block now asks the agent to run
  `npx -y @elevenlabs/cli@latest onboard init` and follow what it prints. The CLI signs
  in and stores an API key in a project env file. The package is in ElevenLabs' own npm
  scope and has no install scripts, but the version is unpinned and the instructions
  arrive at run time, outside this snapshot. The install guide tells users to run or
  approve it themselves and keep the env file out of version control. No telemetry,
  hooks or new scripts were added.
- **LiveKit** moved from `5d7488b` to `e1195b4`: two prose-only files. Building now
  defaults to LiveKit Inference, a billed LiveKit Cloud feature, and debugging adds an
  audio mode that needs LiveKit Cloud credentials.
- **OpenAI:** the bundled speech and transcribe skills are unchanged upstream and still
  default to models on OpenAI's deprecation list. The install guide says so.
- Pipecat, Cartesia and Twilio bundled files were unchanged.
